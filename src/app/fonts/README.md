APN’s existing Newsreader and Instrument Sans font families, obtained from the official google/fonts repository on 2026-11-15. Both are distributed under their included SIL Open Font License files. Local hosting preserves the existing CSS variables and avoids the Next 14 Google Fonts loader failure when upstream font URLs change.
